## Official implementation references consulted

- Streamlit file uploader: https://docs.streamlit.io/develop/api-reference/widgets/st.file_uploader
- Streamlit downloads: https://docs.streamlit.io/develop/api-reference/widgets/st.download_button
- Structured outputs: https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat

The structured-output adapter uses a strict JSON Schema envelope with either a workflow or a clarification. Local semantic validation is still required after generation. Provider support differs; the local mock tests do not establish live API compatibility for every model.
