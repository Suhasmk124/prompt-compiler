# Proposed IEEE report outline

Target the required 10-page IEEE format. Allocate space after measuring actual results; this outline is not a finished report.

1. Title, team details, abstract and introduction: problem and contribution.
2. Related work: natural-language workflow generation, constrained outputs and iterative correction.
3. Problem formulation: supported operations, typed intermediate representation and task boundaries.
4. Architecture: compilation, validation, correction, execution and export checks.
5. Prompt methodology: exact prompts, decomposition, response schema and retry budget.
6. Dataset: provenance, synthetic fixture design, complexity labels, split policy and reference outputs.
7. Experimental setup: model, provider, settings, package versions and comparison controls.
8. Results: measured validity, correctness, execution, retries, latency and cost, with denominators.
9. Error analysis and ablations: flag/filter confusion, missing fields, ambiguity, feedback effects and limitations.
10. Conclusion and references: findings supported by results and realistic future work.

Some sections will share pages. Do not insert placeholder accuracy numbers or imply that preset demo performance measures an LLM.
